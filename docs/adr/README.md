# Architecture Decision Records

Los ADR documentan decisiones técnicas que afectan varios módulos o son difíciles de
revertir. No reemplazan issues ni documentación de usuario.

## Formato

Cada ADR usa un número secuencial y uno de estos estados:

- `Proposed`
- `Accepted`
- `Superseded by ADR-NNNN`
- `Rejected`

Debe incluir contexto, decisión, consecuencias y alternativas consideradas.
